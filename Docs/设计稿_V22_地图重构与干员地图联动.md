## 0. 设计意图

| 项 | 内容 |
| --- | --- |
| 体验目标 | ①**体力 / 开火 / 开镜这些"等待"看得见**（第一期）；②**每条路都有连接、每段视线都有对应的枪**——玩家在路口有选择、转点有代价、拿什么枪都有主场；③**地图元素是技能的第二种用法**——同一个技能在不同点位产生不同效果，制造"这局去哪打、谁去开路"的战术选择。 |
| 一句面试讲法 | "三条路本身不简单也不复杂，Dust2、Bind 都是三路。我们的问题是**三条路平行且中段不连通、视线 90 米以上、侧路被一扇门锁死**。我做的是：加中段连接让'控中路'有回报，用错位建筑把视线切到每把枪的优势距离里，再把火锅、蛋糕墙、门框这些地图元素变成干员技能的联动点。" |

四条原则：
1. **先诊断、后改图**。每个改动都对应诊断表里的一条问题和一个可测指标。
2. **能在现有 Arena 上改的不重建**。保留出生点、包点、美食设施，降低烘焙和回归成本。
3. **联动有上限**：每个干员 1–2 个联动，每个联动都有时限、至少 2 种反制、规则一眼能读。
4. **和现有设计冲突的地方单独标出**（本稿用"⚠ 冲突"标记），不悄悄覆盖。

### 3.3 对比和推荐

| 维度 | 方案甲：三路 + 中段十字 | 方案乙：枢纽火锅中庭 |
| --- | --- | --- |
| 解决"太简单" | 中段连接 + 夹击路线，三路之间有了变招 | 结构本身就是枢纽，变化最多 |
| 中路价值 | 控中段 = 轮转对等（1.8 → 1.0） | 控中庭 = 控全图，**中路价值最高，但容易"一波定胜负"** |
| 视线 / 枪械生态 | 远距离保留 20–30%，DMR 仍有主场 | 远距离只剩 10–20%，**DMR-3、夜鸦会明显变弱** |
| 美食主题 | 关口火锅 ×2、中庭蒸汽阀、烤串巷、后厨 | 巨型火锅当地标，主题最强、截图最好看 |
| 改造量 | **中**：约 15 个几何改动，出生 / 包点 / 大部分设施不动 | **大**：内圈楼块、主街、中庭、小巷、狙击台、连廊全重做，约占 `Arena.cs` 布局代码 70% |
| 风险 | 低–中：老测试少量坐标要复核 | 高：AI 路线、所有坐标型测试、截图机位、各模式出生点全要重做 |
| 面试讲法 | "数据驱动的最小改动"——诊断 → 针对性改造 → 指标对比 | "从结构上重新设计"——更有作品感，但很难拿出改前改后对比数据 |
| 工作量 | 约 5–7 天（含烘焙） | 约 10–15 天 |

**推荐：方案甲。** 理由：
1. 诊断出的 7 个问题，方案甲都有对应改动，而且每一条都能拿改前 / 改后遥测对比——这是面试里最有说服力的部分。
2. 方案乙会让远距离交战降到 10–20%，等于削弱 DMR-3 和夜鸦，需要连带改枪和英雄，超出"地图"的范围。
3. 方案乙可以留作远期第二张图（例如大乱斗 / 抢食专用的小图），见拍板问题 1 的选项丙。

### 4.2 六个干员逐个设计

每个干员：**现在 → 修改后（新增联动）→ 效果 → 反制 → 为什么**。基础技能数值全部不变（见 V21 稿 §3.1）。

#### ① 猎隼 · 汽水冲刺 → "汽水冲刺 + 可乐弹射"

| 项 | 内容 |

| 现在 | 冲 9 m，落地 1.5 s 减伤 35% + 续杯，2 次 / 12 s |

| 为什么 | 猎隼定位"突击开路"，原来只有"冲 9 米"一种用法。联动让他在**特定点位**有独占的进攻角度，守方必须为这个角度分配注意力——这就是战术选择 |
| ⚠ 冲突 | 无（V21 模板里"方向跟移动键"仍成立） |

### 4.4 复杂度控制：不会出现无解局面

**每个联动的四条硬约束**：

| 约束 | 内容 |
| --- | --- |
| 有时限 | 所有联动产物 ≤ 35 s（最长的是嵌入补洞），回合重置全部清除（`Arena.ResetRound`） |
| 至少 2 种反制 | 见每个干员的"反制"行 |
| 同一元素同一时间只有一种联动 | 先到先得；第二个技能对着已被占用的元素时，预览变红并写"已被占用" |

## 7. 面试讲解卡

### 卡 1 · 体力条：显示阈值，不只显示数量（UI）
- **问题**：体力条只区分"满 / 不满"，放在屏幕底部离准星很远；耗尽后要回到 25 才能冲，条上却没有这条线。
- **我的做法**：挪到准星下方，满了就淡出；画 25% 刻度；四种颜色区分消耗、等待恢复、恢复、锁定；耗尽用喘气声代替文字。
- **为什么**：体力的决策点是两个阈值——0 被锁、25 解锁。HUD 该给的是阈值；新地图轮转约 75 米 = 一管体力加一次恢复，看得见阈值，"要不要冲到底"才是一个决策。

### 卡 2 · 冲刺转开火：表现时长 = 规则时长（UI）
- **问题**：冲刺停下后 0.1–0.32 秒不能开火，这是给守点方的反应窗口；但屏幕上没变化，玩家觉得"枪卡了"。
- **我的做法**：不改时间，让抬枪动画时长等于这把枪的参数，准星同步收拢；写成自动测试，误差不超过 0.05 秒。
- **为什么**：代价看得见，玩家才会把它当成取舍（"拿机枪别冲拐角"）而不是 bug。把"表现跟规则同步"写成测试，以后改数值表现自动跟上。

### 卡 3 · 三条路不是问题，平行且不连通才是（地图）
- **问题**：用户觉得"三条道太简单"。我量了一下：三条路中段 32 米没有任何横向连接；攻方从北路转南路要 138 米、24 秒，守方转点只要 13 秒；侧路还有一扇铁门，AI 在门前卡到超时。
- **我的做法**：不推翻三路，在中段切开两条连接巷，"控中段"就能把攻方转点时间降到 12–13 秒，和守方对等；铁门改成默认开、守方可以关——从"攻方的任务"变成"守方的选择"。
- **为什么**：Dust2、Bind 都是三路，深度来自连接和时间差。把"中路控制价值"量化成"轮转比 1.8 → 1.0"，改完能用遥测验证。

### 卡 4 · 视线长度对齐枪械优势距离（地图）
- **问题**：地图有 5 条 70 米以上的视线，超出所有枪的优势距离；约四分之三的面积在 50 米以上的视线里，等于 DMR 的主场，SMG 和霰弹只有小巷能用。
- **我的做法**：用错位建筑把长街切成 ≤ 48 米的段，主街分两道，楼顶加横幅限制俯视；目标是近 / 中 / 远 = 30 / 45 / 25，并用射线采样测试"不存在 60 米以上的无遮挡视线"。
- **为什么**：枪械设计里每把枪都有优势距离，地图要给每个距离段留出空间，否则数值调得再好，选枪也会被地图决定。

### 卡 5 · 地图元素是技能的第二种用法（联动）
- **问题**：火锅、蛋糕墙、蒸汽这些美食元素很可爱，但几乎不改变交战；干员技能每个只有一种用法。
- **我的做法**：每个干员加 1 个主联动：夜鸦的芥末签射进火锅变成"辣锅"，整个关口暴露；幻频的棉花糖迷雾碰到蒸汽才变成真烟雾；铁幕的布丁盾能嵌进门框当门帘。联动只在固定点位发生。
- **为什么**：联动把"选哪条路"和"带哪个干员"绑在一起——关口是夜鸦和幻频的主场，蛋糕墙是焚芯和铆钉的战场。强度锁在地图点位上，守方能预判，比全局加强更好控制。

### 卡 6 · 克制闭环 + 规则可读（联动）
- **问题**：联动多了容易出现"无解组合"，玩家也不知道哪里能联动。
- **我的做法**：每个联动都有时限、至少两种反制、同一元素同时只能有一个联动，并做了一张优先级表；焚芯 0.9 秒开墙 ↔ 铆钉 1 秒补洞 ↔ 焚芯纸杯对掩体 ×2，形成闭环。可读性接上已有的引导系统：只给能联动的英雄显示气泡，技能预览碰到元素变金色并写出结果。
- **为什么**：系统联动的风险是复杂度失控。先定约束、再定内容；规则在"做之前"就能看到，玩家才会主动去用，而不是碰巧触发。
