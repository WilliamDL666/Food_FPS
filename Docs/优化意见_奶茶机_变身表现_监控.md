# 优化意见：奶茶机 / 变身表现 / 监控

> 先说现状（按代码核对过），再给改法。标 ⚖ 的改规则，需要对局验证。

---

## 一、奶茶机：现在基本没用

### 现状
- 代码里"补满弹药"只是把**当前弹匣装满**（`f.ammo = f.W.magazine`），而本游戏**备弹是无限的**，按 R 换弹就能做到同样的事。
- 真正有用的只有"手雷至少补到 1 颗"。
- 冷却 40 秒。玩家走过去、按住 G、等一下，换来一次"免费换弹"——不划算，所以没人用。

### 改法（三选一）
| 方案 | 奶茶机改成 | 优点 | 风险 |
| --- | --- | --- | --- |
| **甲 · 加料奶茶（推荐）** ⚖ | 喝一杯得到 **"珍珠弹" 20 秒**：子弹打中敌人时溅珍珠，敌人移动 −10%；同时**补 1 颗手雷**、换弹速度 +30%。喝的时候有 1 秒吸管动作，不能开枪 | 一看就懂，美食感强，和"换弹"不重复 | 要调平衡，别和冰淇淋变身的减速重叠太多 |
| 乙 · 奶茶补给站 ⚖ | 补满手雷（2 颗）+ 恢复 30 体力 + 10 秒内冲刺不耗体力 | 规则简单，配合新地图的转点 | 美食感一般 |
| 丙 · 抢食模式专用 | 爆破 / 大乱斗里取消奶茶机；抢食模式里变成"珍珠食材"刷新点 | 减少无用设施 | 地图上少一个机关 |

### 顺手一起改的
- 外卖箱的"补满弹药"同样没意义，改成"补满手雷"或"10 秒换弹加速"。
- 气泡文案写清楚真正的收益，例如"喝奶茶：珍珠弹 20 秒 + 1 颗手雷"。

## 二、变身：现在太难看出来

### 现状
- 变身后头上多一个食物模型（汉堡、蛋糕等），身边有一圈光环；蛋糕形态身体变大。
- 自己这边：**第一人称几乎看不到变化**，只有右侧滚动文字"你变身成了…"和左下角一行"变身：汉堡 18 秒"。
- 敌人那边：远处只能看到头顶一个小物体，看不出你是什么、有什么能力。

### 改法：分"自己看到的"和"别人看到的"

#### 1. 变身瞬间（1 秒内，必须一眼看懂）
| 项 | 做法 |
| --- | --- |
| 屏幕正中大字 | 屏幕中央弹出**菜名大字 + 菜的图标**（例如🍔"汉堡！"），下面一行写能力："正面伤害 −60%"，1.5 秒后缩小飞到左下角 |
| 变身动画 | 第三人称：角色被一阵食物粒子包住，"噗"地变成新造型；第一人称：镜头一缩一弹 + 屏幕边缘闪一圈菜的颜色 |
| 专属音效 | 每道菜一个音效：汉堡"啊呜"、奶茶"咕噜"、火锅"滋啦"、冰淇淋"叮"、饭团"嘿咻" |

#### 2. 变身期间（自己）
| 项 | 做法 |
| --- | --- |
| 第一人称手和枪 | **手套和枪变成对应皮肤**：汉堡 → 手上套面包、枪上夹生菜；冰淇淋 → 枪结霜、手套冰蓝；火锅 → 枪口冒红油热气；奶茶 → 枪上插吸管 |
| 屏幕边框 | 屏幕四角一层淡淡的菜色边框（汉堡金黄 / 冰淇淋冰蓝 / 火锅红 / 奶茶奶棕），不挡中间 |
| 能力图标 | 准星旁边一个小图标 + 倒计时圆环，最后 3 秒闪烁 |
| 能力触发反馈 | 能力生效时有明显反馈：汉堡挡伤害时面包盾"咚"一下亮起；冰淇淋冻住敌人时敌人身上出现冰块；火锅灼烧时敌人冒火 |

#### 3. 变身期间（别人看到）
| 项 | 做法 |
| --- | --- |
| 全身造型 | 不只是头顶一个小物体：**身体套上整套食物外壳**（汉堡 = 上下两片面包夹着、蛋糕 = 整个人变成蛋糕、奶茶 = 身体变成奶茶杯、冰淇淋 = 头顶甜筒 + 身体结霜） |
| 远距离辨识 | 名字条旁加菜的图标；敌人准星对准时显示"汉堡：正面难打，绕后！"这类一句话提示 ⚖ |
| 小地图 | 变身的敌人 / 队友在小地图上图标换成菜的样子 |

#### 4. 变身结束
- 外壳"啪"地碎成食物碎片，屏幕中间小字"变身结束"，而不是只在右侧滚动栏里。

**为什么**：变身是这个游戏最有特色的机制，但现在只靠文字提示，玩家既不知道自己变了什么，也不知道敌人变了什么。表现要做到"不看文字也懂"。

## 三、监控：现在的效果玩家根本感觉不到

### 现状（代码里实际在做什么）
- 监控属于**守方**。镜头会左右扫，进攻方被它看到时，会被**标记 0.6 秒**（守方能透墙看到，小地图上也显示）。
- 进攻方可以把监控打坏（守方打不坏自己的），打坏后播报"守方监控被摧毁"。
- 幻频的棉花糖迷雾罩住监控时，监控在迷雾期间失效。
- 问题：**没有任何画面告诉你"你被监控看到了"，也看不到监控在看哪**，守方也不知道是监控帮他报了点。

### 改法

#### 1. 先让现有效果看得见（纯表现，推荐必做）
| 项 | 做法 |
| --- | --- |
| 监控视野锥 | 地面上画出监控扫过的**半透明扇形**（守方看是蓝色、进攻方看是红色） |
| 被看到的提示 | 进攻方被扫到时，屏幕上方出现**红色眼睛图标 + "被监控看到！"**，监控发出"哔"声 |
| 守方的报点 | 守方小地图上，被监控看到的敌人出现**带监控图标的红点**，播报"监控发现：B 点侧门 1 人" |
| 小地图 / 大地图 | 监控用图标显示位置和朝向，被打坏变灰、被糊住变粉 |
| 造型美食化 | 监控做成**眼睛造型的糖果 / 棒棒糖摄像头**，被打坏时糖壳碎裂 |

#### 2. 加一个"看监控"的玩法 ⚖（参考彩虹六号）
| 谁 | 怎么用 | 效果 |
| --- | --- | --- |
| **守方** | 按一个键（例如 `C`）进入**监控视角**，左右键切换不同监控 | 用监控画面找人，并按中键给队友标点；看监控时自己的身体不动、看不到周围，有被偷袭的风险 |
| **幻频 · 糖丝连线（推荐）** | 幻频的棉花糖迷雾罩住监控时，不只是让它失效，而是用**糖丝"接管"它 8–10 秒**：幻频按 `C` 就能用这个监控的视角看守方 | 进攻方也能用监控，监控变成双方争夺的资源；守方看到监控变粉色，知道被接管了，可以打掉它 |
| 夜鸦 · 芥末签钉监控（备选） | 芥末签钉在监控上，**接管 8 秒**，看到的守方被全队透视 | 和夜鸦的侦察定位吻合；缺点是和幻频的作用重复 |

#### 3. 反制（保证不会太强）
- 被接管的监控会**冒粉色糖丝、发出"滋滋"声**，守方小地图上图标变粉。
- 守方可以打掉被接管的监控（这时守方也能打自己的监控）。
- 看监控时有**明显画面边框**（糖果相机取景框 + 噪点），一次最多看 10 秒，冷却 15 秒。

**为什么**：监控是信息战的核心机制，现在信息只在"后台"流动，双方都感觉不到。让它可见、可用、可争夺，才有战术价值；"幻频用糖丝接管监控"正好契合她"干扰 / 信息"的定位。
