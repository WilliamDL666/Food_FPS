# 场景交互清单（V23，美食模式）

> 按"怎么交互"分类。数值取自当前代码默认值。G = 按住交互键。

## 一、按住 G 使用的设施
| 东西 | 在哪 | 怎么用 | 作用 |
| --- | --- | --- | --- |
| 蒸笼门 | 北 / 南长街关口（x=4） | 守方按住 G 2 秒盖上；任何人按住 1.2 秒掀开 | 默认开着。盖上后长街被封死，只能走旁边的墙洞（打碎木箱钻过去）。盖上时有闷响，远处能听到 |
| 卷帘门 | 包点侧门等处 | 按住 G 1.6 秒升起 / 放下 | 开关通道；升起时有噪音，会暴露位置 |
| 门禁终端 | 门旁边的小屏幕 | 按住 G | 打开对应的门，同时发出警报（暴露位置） |
| 电闸 | 部分区域墙上 | 按住 G | 该区域灯光熄灭 20 秒，变暗 |
| 医疗站 | 出生区附近 | 按住 G | +50 生命、+25 护甲，每回合只能用一次 |
| 零食（餐盘上的小吃） | 散布在街边 | 按住 G 0.5 秒吃掉 | +25 生命（猎隼被动翻倍）；25 秒后刷新（变大模式 8 秒）；满血吃不下 |
| 火锅回血炉 | 夜市主街 | 按住 G 涮一涮 | 每秒 +10 生命，最多回 60；但热气会暴露你 |
| 奶茶机 | 厨房区 | 按住 G | 补满弹药和手雷 |
| 烤箱 | 南后厨 | 按住 G 烤 5 秒 | 枪变"金黄酥脆版"：伤害 +15%，阵亡前一直有效 |
| 冰柜 | 厨房区 | 按住 G | +50 护甲，但移动稍微变慢 |
| 蒸汽阀（茶壶） | 中庭、南后厨 | 按住 G 0.5 秒拧开 | 喷出整片白雾：中庭 9 m / 后厨 7 m，10 秒，冷却 40 秒。外面看不进去，雾里只看得清 2.5 米。子弹和爆炸不受影响 |
| 开大火旋钮 | 北 / 南关口火锅旁 | 按住 G 0.8 秒 | 关口火锅冒出 9 m 整片蒸汽，规则同蒸汽阀 |
| 进雾关阀 | 正在喷雾的阀门 / 旋钮 | 任何人走进雾里按住 G 0.5 秒 | 关掉，1.75 秒内雾散开（反制别人放的雾） |
| 大锅（抢食模式） | 两队各一口 | 带着菜走近交上去；按住 G 偷对面的锅 | 交菜得分；偷对面锅里的食材，对方 −1 分 |

> 全图同时最多 2 片白雾，满了阀门和旋钮就拧不开；双方小地图上都能看到雾区和剩余时间。

## 二、走过去 / 踩上去就生效
| 东西 | 作用 |
| --- | --- |
| 食材 | 走过去自动捡。第二样凑不成菜时要按住 G 才捡。两样凑成一道菜就变身（见第五节）。手上有 1 样时，地图上能配对的那一样会亮光柱 + 边缘箭头 |
| 外卖箱（空投） | 无人机空投，落点地上有提示。抢到：随机变身 + 补满弹药 + 枪变酥脆。爆破模式每回合一次，其他模式约 45 秒一次 |
| 果冻弹床 | 踩上去弹到高处平台。猎隼冲刺中踩上去会触发"可乐弹射" |
| 传菜转盘 | 站上去会被带着转 |
| 火锅（关口 / 场景里的锅） | 站进去会被烫；热气挡视线 |
| 巧克力酱地面 | 减速 |
| 黄油地面 | 打滑 |
| 掉落的枪（大乱斗） | 阵亡的人掉落手里的枪，走过去就捡，20 秒后消失 |

## 三、打它 / 炸它
| 东西 | 怎么触发 | 作用 |
| --- | --- | --- |
| 蛋糕墙 | 射击 / 爆炸 | 一层层被打穿，开出通道；用奶油裱花（BR-5）打是补墙 |
| 墙洞木箱 | 打碎 | 露出墙洞，可以钻过去（蒸笼门盖上时的备用路线） |
| 轻型掩体（黄色灯条） | 打坏 | 掩体消失 |
| 爆炸桶 | 打坏 | 短暂延迟后爆炸，伤害周围的人 |
| 玻璃 | 打碎 | 打开视线 / 可翻窗 |
| 监控摄像头 | 打坏 | 监控失效，不再为守方报点 |
| 曼妥思可乐 | 汽水罐手雷砸中或在 4.5 m 内爆炸 | **可乐喷泉**：2.5 秒、约 9 米高，把附近的人冲上天；冷却 15 秒 |

## 四、食物和食物的反应
| 组合 | 效果 |
| --- | --- |
| 汽水罐手雷 + 曼妥思 | 可乐喷泉，把人冲上天 |
| 奶油裱花（BR-5）打蛋糕墙 | 补墙，不是打穿 |

## 五、凑菜变身（两样食材）
| 菜 | 配方 | 效果 |
| --- | --- | --- |
| 巨型蛋糕 | 面粉 + 鸡蛋 | 体型变大、+100 护甲、移动变慢，冲刺能撞飞敌人 |
| 奶茶杯 | 牛奶 / 茶叶 / 珍珠 任选两样 | 移动加速 30%，开火不耗弹药 |
| 麻辣火锅 | 辣椒 + 火锅底料 | 子弹附带灼烧，身边热浪烫伤敌人 |
| 汉堡 | 面包 + 芝士 | 面包盾：正面受到的伤害减少 60% |
| 冰淇淋 | 冰块 + 糖 | 子弹让敌人减速，2 秒内连中 3 次冻住 1.2 秒 |
| 饭团 | 米饭 + 海苔 | 冲刺时滚成饭团，撞到敌人造成伤害并弹飞 |
| 黑暗料理 | 乱配的任意两样 | 冒绿烟、自己慢慢掉血，但子弹会让敌人看不清 |

## 六、干员技能 × 地图（只有对应干员能用）
| 干员 | 技能 + 地图元素 | 效果 |
| --- | --- | --- |
| 猎隼 | 汽水冲刺中踩果冻弹床 | 可乐弹射：飞得更远（最多 1.6 倍），落地把 3.5 米内的敌人推开（不掉血） |
| 铆钉 | 威化墙贴到被炸开的墙洞 | 补洞，把破口堵上一段时间 |
| 铆钉（副） | 威化墙放在坡道点 | 斜放成约 30° 的坡道，20 秒，能上平时上不去的高处 |
| 铁幕 | 布丁盾放进 5 米内的门框 | 果冻门帘：挡子弹，人能慢慢穿过；穿过的敌人被透视 2.5 秒。包点至少留 2 个入口挂不上 |
| 夜鸦 | 芥末签射进火锅 / 关东煮锅 / 回血炉 | 芥末呛雾：12 米（回血炉 6 米）、9 秒，雾里的敌人被透视、移动变慢；芥末味能穿透蒸汽 |
| 焚芯 | 纸杯蛋糕粘在蛋糕墙上 | 炸出 4 × 3 米的大门（两人并排能过），扬起蛋糕粉尘 |
| 焚芯（副） | 纸杯蛋糕炸到酱料地面 | 巧克力酱变热巧克力 7 秒；黄油整条跑道着火 3.5 秒 |
| 幻频 | 棉花糖迷雾碰到蒸汽源 | 和蒸汽一样大的粉色盲区，最长 8 秒，雾里敌人黏脚；糖味能盖掉芥末 |
| 幻频（副） | 迷雾罩住守方监控 | 迷雾期间监控失效 |

## 七、怎么知道哪些能交互
- 能交互的东西头顶有**气泡**，写着能干什么；用不了时变灰（比如"满血吃不下""还要 N 秒"）。
- 你的干员能联动的地方，准星对准时技能图标会**变金色**，按中键可以给队友标"这儿能联动"。
- 按 **H** 打开帮助：菜谱、地图美食、我的英雄。
- 按 **M** 打开大地图，底部可以切换"机关 / 食材 / 联动"图层，看全图所有交互点。
