# 设计稿 · V21 美食技能 + 可发现性（系统策划）

> 状态：**待用户拍板**。本稿只做诊断和方案，没有改任何代码或数值。
> 用户原话：①"我的角色技能也能不能往美食上靠"；②"捡什么东西有什么用、我能干什么，玩家其实都不知道，你需要怎么修"。
> 依据：README V17–V20、`Docs/战斗设计文档_角色_枪械_3C.md` §1 / §4、`Docs/设计稿_V21优化.md`，以及源码 `Skills.cs`、`GameConfig.cs`、`FoodPlay.cs`、`FoodMarkers.cs`、`FoodMap.cs`、`GameUI.cs`、`Toon.cs`、`Interactables.cs`、`Fighter.cs`。
> 和 `设计稿_V21优化.md` 的关系：那份稿子讲"AI / 数据可信"，这份讲"主题统一 + 玩家看得懂"。两份互不改对方的数值，可以并行。

## 0. 设计意图

| 需求 | 要解决的体验问题 |
| --- | --- |
| 技能美食化 | 帽子、枪、大招、被动都是美食，只有 F 技能还是"战术掩体 / 防护阵列"。一个英雄的四样东西应该是**同一道菜系**，玩家看一眼就能猜出它干什么。 |
| 可发现性 | 规则其实都做了，但大多只在"做完之后"才告诉玩家（播报一行字），或者藏在主菜单图鉴里。要让玩家**在做之前就知道**：捡这个能凑成什么、按 G 会发生什么、我的技能 / 被动 / 大招是什么。 |

两条设计原则：
1. **技能只换皮，不换规则**。"目的 / 规则 / 反制 / 失败代价"框架和所有数值都保留，换的是名字、模型、颜色、音效、文案。想改规则的地方单独列成拍板项。
2. **规则信息全公开，收集只算"做过没做过"**。配方是规则，不应该藏；图鉴的乐趣留在"点亮"和"解锁帽子"上。

**结论**：做得好的是"按 G 的东西"（厨房设施、零食），差的是三类：
- **组合类规则**：食材配方、食物反应、蛋糕墙 + 奶油。
- **英雄自身**：被动不可见，大招没效果说明，技能怎么用不显示。
- **状态类**：冷却中、满血时气泡还在，玩家以为坏了。

## 2. 规则

### 2.1 干员技能美食化

#### 总表（推荐方案）

| 干员 | 旧名 | **新名（推荐）** | 所属菜系 | 规则变化 |
| --- | --- | --- | --- | --- |
| 猎隼 | 推进喷射 | **汽水冲刺** | 快餐：汉堡 + 可乐 | 无 |
| 铆钉 | 战术掩体投放 | **威化饼干墙** | 小吃摊：饭团 / 爆米花 / 威化 | 无（修正文案耐久 450 → 585，见下） |
| 铁幕 | 防护阵列 | **焦糖布丁盾** | Q 弹甜品：布丁 / 果冻 | 无 |
| 夜鸦 | 侦测箭 | **芥末探签** | 日料：寿司 + 芥末 + 竹签 | 无 |
| 焚芯 | 定向爆破 | **点火纸杯蛋糕** | 生日派对：纸杯蛋糕 + 蜡烛 | 无 |
| 幻频 | 信号噪幕 | **棉花糖迷雾** | 糖果铺：甜甜圈 / 糖粒 / 糖霜 | 无 |

命名规则：①4 个字左右，HUD 技能条宽 200 像素放得下；②**不能包含 `ToonAssets.FoodWords` 的替换词**（"炸弹""安装""拆除""资金"等），否则会被自动替换（比如"跳跳糖炸弹"会变成"跳跳糖蛋糕"）；③一看名字就能猜出是"移动 / 挡子弹 / 看人 / 炸 / 干扰"。

#### ① 猎隼 · 汽水冲刺

| 项 | 内容 |
| --- | --- |
| 视觉 | 0.15 秒前摇：摇一下手里的汽水罐，罐口冒泡。冲刺时背后喷焦糖色可乐泡沫，残影改成半透明气泡色。落地"打个饱嗝"，脚下炸开一圈白色气泡冲击波 |
| 音效 | 前摇：开罐"嘶"（`food_fizz`）；冲刺：气泡声；落地：打嗝（新）+ `food_boing`。**音量和可听距离不低于现在的 thrusterFire（40 米）**，因为反制靠听 |
| 文案 | 摇一摇汽水，喷着可乐冲出去 9 米。冲完打个饱嗝：1.5 秒减伤 35%，弹匣直接续杯 |
| 规则 | 不变 |
| 主题一致性 | 帽子汉堡 + 大招"双层汉堡冲撞" + 被动"吃零食翻倍" = 快餐吃货；汽水配汉堡。"续杯"对应立即装填，也接上招牌枪珍珠奶茶 |

| 备选 | 取舍 |
| --- | --- |
| **汽水冲刺（推荐）** | 和帽子 / 大招同一套餐；喷气 = 汽水喷，视觉直观。和全员通用的"汽水罐手雷"同属汽水，颜色要区分开（冲刺用焦糖棕，手雷保持原色） |
| 珍珠弹射 | 吸管倒喷珍珠反推，接招牌枪；但珍珠就是 SMG-7 的子弹，满屏珍珠会让人以为在开火 |
| 番茄酱滑行 | 好玩；但"滑"会让人以为留下了打滑地面，和黄油规则混淆，等于暗示了不存在的规则 |

#### ② 铆钉 · 威化饼干墙

| 项 | 内容 |
| --- | --- |
| 视觉 | 预览：半透明威化格子（合法绿 / 不合法红保留）。部署 0.6 秒：施工光束改成爆米花机口挤出奶油，威化一层层叠起来（时长不变）。夹心奶油是队伍颜色。耐久掉到 2/3、1/3 时出现裂纹、掉饼干渣 |
| 音效 | 部署：挤奶油 `food_squish` + 咔嚓；被打：脆响；碎掉：大声 `food_popcorn` |
| 文案 | 按住 F 预览，松开在面前立一块威化饼干墙。宽 3.6 米、耐久 585、存在 18 秒，敌我都能打碎 |
| 规则 | 不变 |
| **和现有设计冲突** | 文案和战斗设计文档 §4.2 都写"耐久 450"，但美食模式下 `DeployedCover.hp = CoverHp × 1.3`（铆钉被动）= **585**（`Skills.cs` 459 行）。建议文案改成"耐久 585（含被动）"，数值不动 |
| 主题一致性 | V19 地图墙面就是"威化格墙"，视觉语言现成。和大招"饭团城墙"形成对比：**威化 = 高、挡人、不能翻；饭团 = 矮、能翻**，一高一矮，玩家能凭外形分清 |

| 备选 | 取舍 |
| --- | --- |
| **威化饼干墙（推荐）** | 外形本来就是平板，最像掩体；地图已有同款材质 |
| 爆米花桶墙 | 接招牌枪爆米花机；但一排圆桶看不出"平的、能挡子弹"，边缘判定也难读 |
| 外卖披萨盒 | 接外卖玩法；但披萨是特别帽子（赢一场解锁），撞概念 |

#### ③ 铁幕 · 焦糖布丁盾

| 项 | 内容 |
| --- | --- |
| 视觉 | 身前"啵"地立起一块 4.4 × 2.8 米半透明布丁墙，顶上一层焦糖。被打会像果冻一样抖（复用 `FoodJiggle`）。血越少颜色越淡、越像化开。底座保留队伍颜色发光条 |
| 音效 | 出现：低音 `food_boing`；被打：软软的噗噗声；碎掉：`food_splat` |
| 文案 | 在身前立起一块布丁盾，只挡正面，Q 弹承伤 650，持续 8 秒；举盾时自己走得慢 |
| 规则 | 不变。**透明度不能低于现在的全息板**：双方都能隔着盾看到人，这是现有规则的一部分 |
| 主题一致性 | 帽子布丁 + 大招果冻罩 + 被动"爆炸减半"（布丁吸震）= Q 弹防守家族 |

| 备选 | 取舍 |
| --- | --- |
| **焦糖布丁盾（推荐）** | 和帽子、大招一个家族；"Q 弹挡子弹"好理解 |
| 冰糖玻璃盾 | 裂纹能很好地显示血量；但"冰"会和冰淇淋变身、冰柜冰护甲混淆 |
| 寿司竹帘 | 接招牌枪回转寿司；但竹帘不透明，要么改规则（挡视线），要么画成透明竹帘，很别扭 |

#### ④ 夜鸦 · 芥末探签

| 项 | 内容 |
| --- | --- |
| 视觉 | 射出一根竹签（糖葫芦签），签头裹一团绿芥末，钉在墙 / 地上。扫描时芥末"呛"出一圈黄绿色气味波（替换紫色扫描球）。被发现的敌人头顶冒一个"呛！"，透墙高亮照旧 |
| 音效 | 发射"嗖"；钉入：竹签扎木头声；扫描：吸鼻子 + 喷嚏（新）；滴答声保留（反制靠听） |
| 文案 | 射出一根芥末签，钉住 1 秒后放出芥末味：14 米内闻到的敌人全队可见 5 秒，3 秒后再呛一次。一枪就能打掉 |
| 规则 | 不变 |
| 主题一致性 | **四样全对上**：被动"芥末标记"、招牌枪冰糖葫芦（竹签）、帽子寿司、大招"回转寿司雷达"（寿司配芥末）。被动和技能用同一种黄绿色，玩家会理解成"夜鸦 = 芥末 = 被看见" |

| 备选 | 取舍 |
| --- | --- |
| **芥末探签（推荐）** | 和被动、枪、帽子、大招全部同源 |
| 烤串探香 | "闻到香味就暴露"好理解，接"烤"的交互；但和帽子寿司无关 |
| 糖葫芦信标 | 最直接；"信标"还是军事词 |

颜色注意：芥末黄绿要和黑暗料理的绿烟、茶叶的绿色拉开（偏黄、偏亮）。

#### ⑤ 焚芯 · 点火纸杯蛋糕

| 项 | 内容 |
| --- | --- |
| 视觉 | 扔出一个插着烟花蜡烛的纸杯蛋糕，"啪"地粘在落点。0.9 秒内蜡烛引信滋滋燃烧，**红色预警圈和填充保留**（预警的颜色语义不能变）。爆炸 = 火光 + 奶油 + 彩纸。原地留下 5 秒"焦糖火"（橙色地面火） |
| 音效 | 引信"滋—滋—"，**节奏保持 0.15 秒一次、可听距离 35 米**，替换 error 蜂鸣；爆炸：`boom` + `food_confetti` |
| 文案 | 扔出点火纸杯蛋糕，0.9 秒后炸开：最高 65 伤害，对掩体 ×2，留下 5 秒焦糖火。听到滋滋声快跑 |

| 备选 | 取舍 |
| --- | --- |
| **点火纸杯蛋糕（推荐）** | 和帽子、大招最统一；有和目标蛋糕混淆的风险，靠大小和红圈区分 |
